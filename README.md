一个用于管理定时消息任务的桌面辅助工具，支持好友管理、消息规则、定时执行、运行记录与结果核对。

A desktop helper for scheduled messaging workflows, with contact rules, message scheduling, run history, and result review.

![Douyin Fire application interface](docs/images/app-overview.png)

## ✨ 功能 / Features

- **好友管理 / Contact management：** 从聊天列表添加好友或手动管理联系人
- **消息规则 / Message rules：** 为联系人配置文字、图片与发送规则
- **定时任务 / Scheduling：** 设置每日运行时间与自动任务
- **运行记录 / Run history：** 查看任务执行状态和发送结果
- **人工核对 / Manual review：** 对无法确认的发送结果进行人工检查

## 🚀 安装 / Install

**macOS / Linux**

```bash
curl -fsSL https://github.com/xiaoyoumi9924/douyin-fire/releases/latest/download/install.sh | bash
```

**Windows PowerShell**

```powershell
irm https://github.com/xiaoyoumi9924/douyin-fire/releases/latest/download/install.ps1 | iex
```

安装完成后，按应用说明打开本地面板、登录、配置联系人并设置任务时间。

After installation, follow the app instructions to open the local panel, sign in, configure contacts, and set the schedule.
