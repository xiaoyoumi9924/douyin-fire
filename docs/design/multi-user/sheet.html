多用户模块 · 本地多成员

一台电脑，多人轮流使用：各自登录、各自的数据分区，成员之间看不到好友、消息和运行记录。自动任务按成员排队执行。示例成员与数字仅用于说明版式。

用户块 角色徽标 成员行 进度条 侧栏 236px

01登录未登录时全屏出现，不带侧栏；选择成员 + 密码，一次只登录一个人

02用户与成员管理员页面：身份卡 + 成员列表 + 数据边界说明；侧栏底部是切换入口

03关键弹层切换用户 / 添加成员 / 删除成员；删除要求输入名字并选择数据处理方式
