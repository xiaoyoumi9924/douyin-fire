# Windows 自动运行教程

> 目标：让应用每天在固定时间自动发送，不需要一直开着窗口。
>
> 适用版本：Windows 10 / 11。

## 1. 安装到固定目录

1. 下载 Windows 版安装包（`.exe`），双击安装。
2. 安装器会让你选择目录：保持默认，或选一个**不会被清理软件删除**的固定路径。
3. 不要安装在临时目录、下载目录，也不要装完再把整个目录移动位置。

应用数据保存在：

```
%LOCALAPPDATA%\Douyin Fire\
```

重装应用不会丢数据，但移动安装目录会让计划任务指向旧路径（见第 6 节）。

## 2. 先手动跑通一次

在设时间之前，先确认整条链路是通的：

1. 扫码登录；
2. 「好友管理」确认好友备注名；
3. 「消息管理」保存今天要发的内容；
4. 回首页点「立即发送」，在确认窗口核对好友与消息，等它跑完。

「登录与记录」里看到成功记录，再去做第 3 步。

## 3. 设置每日运行时间

1. 打开「自动任务」，选择小时和分钟；
2. 点「保存时间」；
3. 页面显示「今天 / 明天 HH:MM」，说明计划任务已写入。

底层会做两件事：

- 在数据目录生成包装脚本 `%LOCALAPPDATA%\Douyin Fire\run-scheduled.cmd`；
- 调用 PowerShell 注册一个名为 **DouyinAutoFire** 的每日计划任务，以**当前用户**身份运行。

任务设置里已经包含：

- `StartWhenAvailable`：错过时间点（睡眠 / 关机）后，恢复时补跑；
- `AllowStartIfOnBatteries`：笔记本用电池时也允许运行；
- `ExecutionTimeLimit = 2 小时`：防止卡住的任务一直挂着。

## 4. 验证计划任务

在 PowerShell 或 CMD 里执行：

```powershell
schtasks /Query /TN DouyinAutoFire /V /FO LIST
```

也可以打开「任务计划程序」，在「任务计划程序库」里找到 `DouyinAutoFire`，看「触发器」和「上次运行结果」。

## 5. 关掉应用还会跑吗？

会。计划任务直接调用后台程序，不依赖窗口是否打开。
设好时间后可以关闭应用，也可以重启电脑——只要到点时**电脑开机、并且登录的是当前这个用户**。

因为任务是交互式用户任务，以下情况到点不会执行：

- 电脑关机；
- 停留在登录界面 / 锁屏但未登录；
- 切换到了另一个 Windows 用户。

## 6. 睡眠、关机与补跑规则

| 情况 | 行为 |
| --- | --- |
| 到点电脑醒着且已登录 | 正常执行 |
| 到点电脑睡眠 | 唤醒后由 `StartWhenAvailable` 触发补跑 |
| 到点电脑关机 | 开机并登录后补跑 |
| 当天已经成功跑完 | 后续检查直接跳过，不会重复发 |
| 当天已尝试 3 次仍失败 | 当天不再自动重试，等第二天 |

补跑还要满足一个条件：当前时间已经过了你设定的时刻。
如果当天过了设定时间才第一次保存计划任务，今天不会立刻补发，从下一个设定时间开始。

> 笔记本合盖休眠、或电源策略把机器彻底关机，仍然会错过。需要长期稳定运行时，建议接电源并关闭睡眠，或改用一台常开的机器。

## 7. 移动或更新应用之后

计划任务里记录的是包装脚本的绝对路径。下面这些操作会让它失效：

- 把安装目录整个移动到别处；
- 覆盖安装到另一个目录；
- 卸载后重新安装到不同位置。

修复方式：重新打开应用，在「自动任务」里再点一次「保存时间」。

## 8. 日志与排查

| 位置 | 内容 |
| --- | --- |
| 面板「登录与记录」 | 每天的成功 / 失败 / 待核对好友 |
| `%LOCALAPPDATA%\Douyin Fire\artifacts\run.log` | 每次运行的主日志 |
| `%LOCALAPPDATA%\Douyin Fire\artifacts\result.json` | 最近一次运行结果 |
| `%LOCALAPPDATA%\Douyin Fire\artifacts\run-history.jsonl` | 历史运行记录 |

常见问题：

- **保存时间时报错**：多数是安全软件或组策略拦了计划任务。先退出安全软件的"任务计划防护"，或用管理员身份重新打开应用再保存一次。
- **任务存在但到点没跑**：在任务计划程序里看「上次运行结果」，检查「条件」页是否勾了"只在计算机空闲时运行"（本应用不会勾，但要确认没被其他策略覆盖）。
- **日志里有"登录状态已失效"**：抖音登录过期，重新扫码登录，计划任务不用改。
- **日志里有"要求进行安全验证"**：抖音风控，应用会主动停止，隔一段时间再试。
- **好友被标记为"待核对"**：上一条消息结果不确定，为避免重复发送，应用当天不会自动重发，请在面板里手动确认。

## 9. 修改或停止

- **改时间**：在「自动任务」重新选择并「保存时间」即可，任务会被覆盖更新。
- **停止自动运行**：

  ```powershell
  schtasks /Delete /TN DouyinAutoFire /F
  ```

  也可以打开任务计划程序，右键 `DouyinAutoFire` → 删除。

- **卸载应用前**：先执行上面的删除命令，否则系统会不断尝试运行一个已经不存在的脚本。

## 10. 需要一台常开的机器？

Windows 台式机接电源常开即可。如果是笔记本或经常关机，建议用一台常开的 Linux 小主机 / 云服务器，见 [Linux 自动运行教程](automation-linux.md)。
