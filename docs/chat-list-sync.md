# 同步聊天列表

在「好友管理」点击「同步聊天列表」，等待读取完成，勾选需要续火花的好友，再点击「添加所选好友」。新名单会追加到当前账号，保留原来的好友顺序和消息设置；没有勾选的会话不会添加，已存在的好友不会重复添加。

弹窗支持搜索和选择当前搜索结果。已添加的名称会标记并禁用选择；读取时发现同名会话或不支持的名称，会提示手动核对。列表来自抖音网页版聊天会话，可能包含群聊，不等于完整好友通讯录。

同步只读取会话名称、用于区分重复行的页面标识，以及标题旁已识别的可见火花天数标记，不打开会话、不读取消息预览、不发送消息，也不生成截图或追踪文件。读取使用当前账号的登录凭证，账号停用时也能同步，便于首次配置。

为避免持续滚动，单次读取最多 500 个条目、80 轮滚动，总超时为 120 秒。页面滚动未完成、没有可靠滚动容器或达到上限时，会显示列表可能不完整。关闭弹窗后任务仍可在后台完成，重新打开可接回正在运行的读取任务。

读取结果临时保存在该账号的 `artifacts/chat-list.json` 中，包含名称，不能公开分享。文件不进入 Git 或安装包；macOS/Linux 文件权限为 0600。重新同步会替换结果，重新扫码、导入或清除登录凭证会清除旧结果；添加时会校验同步批次，拒绝使用其他账号或旧批次的数据。

当前最多保存 50 位续火对象，超过时需减少勾选数量。使用高级 `targets[].messages` 配置的用户，需要已有默认 `messages` 才能给新好友套用默认消息；没有默认消息时不会擅自复制其他好友的专属文案。

从源码运行只读同步：

```bash
.venv/bin/python scripts/sync_friends.py
# 多账号配置可指定某个账号，即使该账号尚未启用：
.venv/bin/python scripts/sync_friends.py --account second
```

本功能仍沿用现有按备注/昵称搜索的发送流程；同步时发现的同名会话会阻止勾选；实际发送时发现多个同名候选也会停止处理该好友，不再选择第一条。每条消息在统一入口及关键操作前复核会话；已确认的会话发生变化时停止本轮。当前尚未启用远端稳定身份绑定，不能识别所有同名会话切换，也不能保证核对之后页面不发生变化。添加前核对对象，名称变化后重新检查。

## 火花状态

读取仅接受 `ConversationItemTagNextToTitle` 区域内可见且唯一的 `commonStreaknormalText` 标记，并严格校验天数格式。未读到、隐藏、冲突、同名及无效数字不映射为有效天数。读取时间记录在账号自己的同步缓存中，网页仅展示当日有效的数据；跨天显示待更新，页面打开期间也会定期检查过期状态。这个有效期是本项目的数据新鲜度规则，不是抖音火花的失效时间。

当前识别逻辑基于已知页面标记和本地模拟 DOM 验证，没有在本轮自动登录抖音核实真实页面。真实读取结果需要用户下次同步时确认，标记不匹配时保持未知，不尝试从消息预览、时间数字或发送历史猜测。
